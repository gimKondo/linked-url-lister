# データモデル: URL正規化の強化

## 概要

この機能は既存のURL正規化処理を拡張するものであり、新しいエンティティの追加はない。既存の`NormalizeURL`関数の入出力と処理フローを文書化する。

## 既存エンティティ

### url.URL（Go標準ライブラリ）

URL正規化で操作する主要フィールド:

| フィールド | 型 | 説明 | 正規化での処理 |
|-----------|-----|------|---------------|
| Scheme | string | プロトコル（http/https） | 変更なし |
| Host | string | ホスト名とポート | 変更なし |
| Path | string | パス部分 | 正規化対象 |
| RawQuery | string | クエリ文字列 | 空に設定（除去） |
| Fragment | string | フラグメント | 空に設定（除去・既存） |

## 正規化処理フロー

```
入力: 相対または絶対URL文字列 + ベースURL

┌─────────────────────────────────────┐
│ 1. URLパース                         │
│    url.Parse(href)                  │
└─────────────────┬───────────────────┘
                  ▼
┌─────────────────────────────────────┐
│ 2. 絶対URL解決                       │
│    baseURL.ResolveReference(parsed) │
└─────────────────┬───────────────────┘
                  ▼
┌─────────────────────────────────────┐
│ 3. フラグメント除去（既存）           │
│    resolved.Fragment = ""           │
└─────────────────┬───────────────────┘
                  ▼
┌─────────────────────────────────────┐
│ 4. クエリパラメータ除去（新規）       │
│    resolved.RawQuery = ""           │
└─────────────────┬───────────────────┘
                  ▼
┌─────────────────────────────────────┐
│ 5. パス正規化（新規）                │
│    resolved.Path = path.Clean(...)  │
│    - 連続スラッシュ → 単一スラッシュ │
│    - ドットセグメント解決            │
└─────────────────┬───────────────────┘
                  ▼
┌─────────────────────────────────────┐
│ 6. 空パス処理（新規）                │
│    "" または "." → "/"              │
└─────────────────┬───────────────────┘
                  ▼
┌─────────────────────────────────────┐
│ 7. トレイリングスラッシュ除去（新規） │
│    "/" 以外で末尾の "/" を除去       │
└─────────────────┬───────────────────┘
                  ▼
出力: 正規化された *url.URL
```

## 正規化ルール

### 入力例と出力例

| 入力URL | 正規化後URL | 適用ルール |
|---------|------------|----------|
| `/page?utm_source=twitter` | `/page` | クエリパラメータ除去 |
| `/page#section` | `/page` | フラグメント除去 |
| `/page?a=1#sec` | `/page` | クエリ＋フラグメント除去 |
| `/docs/guide/` | `/docs/guide` | トレイリングスラッシュ除去 |
| `/` | `/` | ルートパス保持 |
| `/docs//guide` | `/docs/guide` | 連続スラッシュ正規化 |
| `/docs/../guide` | `/guide` | ドットセグメント解決 |
| `` (空) | `/` | 空パス正規化 |
| `/page.html` | `/page.html` | 拡張子ありはそのまま |

## バリデーションルール

- スキームがhttp/https以外の場合は無効（`IsValidURL`で判定）
- パースエラーの場合はエラーを返す
- 空の入力は有効（ベースURLがそのまま返る）

## 状態遷移

この機能は状態を持たない純粋な関数処理のため、状態遷移は適用外。
